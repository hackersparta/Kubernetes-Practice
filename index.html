🚀 Local Kubernetes Setup Guide

Follow these steps to create a production-like 3-node Kubernetes cluster on your Windows machine using Kind (Kubernetes in Docker).

1

Install Kind on Windows

Download the Kind binary and add it to your PATH:

curl.exe -Lo kind-windows-amd64.exe https://kind.sigs.k8s.io/dl/latest/kind-windows-amd64 move kind-windows-amd64.exe C:\Windows\System32\kind.exe
2

Create Cluster Configuration

Save this as kind-config.yaml:

kind: Cluster apiVersion: kind.x-k8s.io/v1alpha4 nodes: - role: control-plane - role: worker - role: worker
3

Launch Your Cluster

kind create cluster --name uat-playground --config kind-config.yaml kubectl cluster-info --context kind-uat-playground
4

Deploy Test Workloads

Create deployments with node affinity (4 pods per worker):

kubectl create deployment nginx-worker1 --image=nginx --replicas=4 kubectl create deployment nginx-worker2 --image=nginx --replicas=4 kubectl get pods -o wide
5

Verify & Experiment

Check node distribution and start experimenting!

kubectl get nodes kubectl top pods kubectl describe node kind-worker
