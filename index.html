Local Kubernetes Playground — Quick Start

Use Kind (Kubernetes IN Docker) to create a 3-node cluster on your Windows machine. Then deploy 3 small apps (4 pods per node) using nodeAffinity.

1
Install Kind (Windows)

Download kind.exe and place it on your PATH. Example: C:\tools\kind.exe

2
Cluster config

Use a kind config with 1 control-plane and 2 workers. Then remove the control-plane taint for experiments.
